# defect-form-extractor

번영로 센트리지 3단지 **세대별 3년차 하자보수 신청서**와 같은 2페이지 고정 양식의 스캔 PDF를 읽어 Excel로 정리하는 Windows 프로그램입니다.

## 목표

- 완전 로컬 처리
- OpenAI/Gemini 등 API 사용 없음
- API 키 필요 없음
- 유료 OCR 서비스 사용 없음
- 문서/전화번호/성명 등 개인정보를 외부 서버로 전송하지 않음

OCR은 무료 오픈소스 PaddleOCR 한국어 모델을 PC에서 실행합니다. 최초 실행 시 OCR 모델 파일을 내려받기 위해 인터넷 연결이 필요할 수 있으며, 이후에는 로컬 캐시를 사용합니다.

## 자동 정리 항목

- 동 / 호수 / 소유자성명 / 연락처 / 주말작업가능여부
- 3년차 공사명 / 세부공종 / 하자내용
- 위치 (거실, 주방, 침실1/2/3, 실외기실, 대피공간, 공용욕실, 부부욕실 등)
- 부위 (벽, 바닥, 벽부등, 배전함, 보일러, 분배기, 신발장, 욕실, 창틀 등)
- 하자유형 (깨짐, 파손, 들뜸, 오염, 작동불량, 누수, 균열 등)
- 비고 / 원본페이지 / OCR신뢰도

## 정확도를 높이기 위한 방식

1. PDF를 고해상도 이미지로 렌더링합니다.
2. 양식이 고정되어 있다는 점을 이용해 **기본정보와 각 공종 작성칸을 좌표로 분리**합니다.
3. 인쇄되어 있는 공사명/세부공종은 OCR하지 않고 양식의 행 위치로 확정합니다.
4. 실제 수기 작성영역만 한국어 OCR에 넣습니다.
5. 인식된 문장에서 위치/부위/하자유형을 현장용 키워드 사전으로 분류합니다.
6. OCR 신뢰도가 낮거나 분류가 되지 않은 항목은 **비고에 '확인 필요'**로 남기고 노란색으로 표시합니다.
7. 프로그램 안에서 원본 페이지를 보면서 결과를 직접 수정한 뒤 Excel로 저장할 수 있습니다.

> 한글 수기는 필체에 따라 오인식이 발생할 수 있습니다. 특히 성명, 전화번호, 흘려쓴 긴 문장은 반드시 노란색 행을 검수해 주세요.

## 실행 방법

GitHub Releases에서 최신 Windows 압축파일을 받아 압축을 푼 뒤 `DefectFormExtractor.exe`를 실행합니다.

첫 OCR 실행 때 PaddleOCR 한국어 모델 다운로드가 진행될 수 있습니다. 모델 다운로드는 무료이며 API 키가 필요 없습니다.

## 기본 사용법

1. `PDF 선택`
2. `자동 인식`
3. 노란색 `확인 필요` 행을 원본 미리보기와 비교해 수정
4. `Excel 저장`

## 현재 지원 양식

현재 v0.1.0은 대화에서 제공된 `260923 접수.pdf`와 동일한 **번영로 센트리지 3단지 아파트 세대별 3년차 하자보수 신청서 (1/2, 2/2)** 양식을 우선 지원합니다.

스캔 여백/기울기/축척이 크게 달라지면 고정 좌표 조정이 필요할 수 있습니다.

## 개발 환경

Python 3.11 / PySide6 / PyMuPDF / PaddleOCR / PaddlePaddle CPU / openpyxl / PyInstaller

## 개인정보

선택한 PDF나 OCR 결과를 외부 서버로 업로드하는 코드는 없습니다.
